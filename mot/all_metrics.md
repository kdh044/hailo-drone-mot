# 트래커 전체 지표

VisDrone2019-MOT val 7개 영상 전체 합산(TrackEval COMBINED). 표마다 HOTA 순서. 아직 실행이 끝나지 않은 트래커는 빠져 있다.

**지표 뜻**

- **HOTA**: 검출과 연결을 함께 보는 대표 지표. √(DetA × AssA)
- **DetA**: 검출 정확도. 정답 박스를 얼마나 찾았나
- **AssA**: 연결 정확도. 같은 객체를 같은 ID로 얼마나 오래 이어 갔나
- **LocA**: 찾은 박스 위치가 정답과 얼마나 잘 겹치나
- **DetRe / DetPr**: 검출 재현율(놓치지 않은 비율) / 정밀도(헛검출 아닌 비율)
- **IDF1**: ID를 기준으로 본 F1. 같은 객체에 같은 ID가 붙은 비율
- **MOTA**: 1 − (놓침 + 헛검출 + ID 바뀜) / 정답 수
- **IDSW**: ID가 바뀐 횟수, **Frag**: 트랙이 끊긴 횟수, **FP**: 헛검출, **FN**: 놓친 정답
