# 트래커 전체 지표

검출 모델별 표 2개(S, Tiny)이고, **통합 HOTA 순서로 정렬**했다(통합 = 사람+차를 한 번에 채점). 실험이 끝나는 대로 이 표를 계속 갱신한다.

- E2E FPS: 사진 열기(작게 풀기)부터 검출·후처리·트래커까지 전부 포함한 실제 속도. 4개 영상(1344~4K)에서 측정, 다른 작업을 멈춘 상태.
- 지표: HOTA = √(DetA × AssA), DetA = 검출 정확도, AssA = 연결 정확도, IDF1 = 같은 객체에 같은 ID가 붙은 비율, IDSW = ID 바뀐 횟수.
